# Obehi Energy

Obehi Energy is a responsive electricity and energy services website built with HTML, CSS, JavaScript, SCSS, and Less.

The project was created as a frontend development project to practice building multi-page websites, responsive layouts, navigation, reusable styling, interactive pages, and structured web content.

## Features

* Responsive energy and electricity website
* Multi-page website structure
* Electricity service information
* Business unit information
* Electricity bill checking section
* Online payment section
* FAQ and information pages
* Newsroom section
* Contact page
* Network information
* Whistleblowing information
* Responsive navigation
* Mobile-friendly layouts
* Structured content and image sections

## Technologies Used

* HTML
* CSS
* JavaScript
* SCSS
* Less
